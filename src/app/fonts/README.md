# Typefaces

The Trabat Display files are a commercial typeface (Gian Studio) and are kept
out of this repository. Put your licensed copies in this folder before running
or building the site, under exactly these names:

- `TrabatDisplay-Condensed.otf` — the labels
- `TrabatDisplay-SemiCondensed.otf` — titles and figures inside a text panel
- `TrabatDisplay-Regular.ttf` — only for the width comparison on the case page

They are loaded in `src/app/fonts.ts`. Without them the site does not build.
