# Pictures for inside the block

Put an image here for any of the shapes and it appears inside the block on the logo page:

- `square.jpg` — the square
- `portrait.jpg` — the portrait
- `landscape.jpg` — the landscape
- `post.jpg` — the 4:5 post

`.jpg`, `.jpeg`, `.png`, `.webp` and `.avif` all work. A shape without a file stays plain white. The picture is cropped from the middle to fill its shape.
